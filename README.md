# telogator-utils

A suite of Python and Bash utilities for summarizing, filtering, and aggregating chromosome-specific telomere length (TL) data generated by [Telogator2](https://github.com/zstephens/telogator2) long-read sequencing outputs.

This pipeline extracts representative telomere and telomere variant repeat (TVR) lengths per chromosome arm (p and q), filters data by haplotype or collapsed allele models, and aggregates autosomal data across entire sample cohorts to generate multi-condition summary matrices.

## Pipeline Overview

The workflow consists of two main steps:
1. **Per-Sample Summarization:** Maps raw allele lengths to specific chromosome arms and filters for top-supported reads (Standard or DP>=5 Stringency).
2. **Cohort Aggregation:** Compiles all individual sample summaries, isolates autosomes (excluding sex chromosomes to prevent bias), and computes minimum, maximum, median, average, and standard deviation across five biological conditions.

## System Requirements

* **Operating System:** Linux/Unix/macOS (Bash shell)
* **Python:** 3.7+
* **Dependencies:** `pandas` (>=1.0.0), `numpy` (>=1.18.0)

You can install the required Python packages using:
```bash
pip install pandas numpy

```

## Repository Files

* `get_tal_summary_stats.py`: Core processing script for per-sample chromosome summarization.
* `get_tal_summary_stats_dp5.py`: Low-stringency variant of the summary script requiring a minimum depth of 5 supporting reads.
* `submit_4_tal_summary_stats_w_config.sh`: Bash wrapper to execute Step 1 in parallel across multiple samples.
* `template_4.tal.summary.config`: Configuration template for Step 1.
* `get_autosomes_tal_summary_stats_aggregated_4_multi_condn.py`: Core processing script to aggregate cohort data.
* `submit_4_autosomes_tal_summary_stats_aggregate_w_config.sh`: Bash wrapper to execute Step 2.
* `template_4.tal.aggregate.config`: Configuration template for Step 2.

## Input Data Schema

### 1. Telogator Allele Output (`<SPECIES>_tlens_by_allele.tsv`)

Raw outputs from upstream Telogator tools. The pipeline extracts:

* `chr` (Chromosome ID)
* `TL_p75` (Telomere length 75th percentile)
* `read_TLs` (Comma-separated individual read lengths)
* `tvr_len` (Telomere variant repeat length)
* `read_ids` (Comma-separated supporting read identifiers)

### 2. Chromosome Reference Table

A TSV mapping table is required to link chromosome names to accession numbers.

* **Columns Required:** `REF_ACC` (Sample ID), `CHROM` (Chromosome Number), `GB_ACC` (GenBank ID), `RS_ACC` (RefSeq ID).

## Usage Instructions

### Step 1: Generate Per-Sample Summaries

1. Copy `template_4.tal.summary.config` to create your own configuration file (e.g., `my_run.summary.config`).
2. Update the paths in the config file to point to your raw TSVs and reference table.
3. Select your `ALLELE_MODE` (`collapsed` or `haplotype`).
4. Execute the wrapper:
```bash
bash submit_4_tal_summary_stats_w_config.sh my_run.summary.config

```



*(To use the DP>=5 stringency filter instead, edit the `SCRIPT` variable in your config to point to `get_tal_summary_stats_dp5.py` before running).*

### Step 2: Aggregate Autosomal Data for the Cohort

1. Copy `template_4.tal.aggregate.config` to create your own configuration file (e.g., `my_run.aggregate.config`).
2. Update the `INPUT_DIR` to point to the output folder generated in Step 1.
3. Set your desired `OUTPUT_DIR` and `FINAL_OUTPUT` filename.
4. Execute the aggregator:
```bash
bash submit_4_autosomes_tal_summary_stats_aggregate_w_config.sh my_run.aggregate.config

```



## Output Formats

### 1. Per-Sample Summaries (`*.all.chr.tal.summary.tsv`)

Contains mapped chromosome arms, allele ranks, p75 lengths, maximum individual read lengths, TVR lengths, and clustering metrics.

### 2. Aggregated Matrix (`*.aggregate.summary_5_condn.tsv`)

A master matrix where rows are samples and columns contain the Min, Max, Median, Mean, and Standard Deviation for five specific analytical conditions across all autosomes:

1. `TL_p75` + `tvr_len`
2. `TL_p75` only
3. `max_individual_read_TL`
4. `max_individual_read_TL` + `tvr_len`
5. `tvr_len` only

Missing samples or autosomes that fail processing are logged in `no_tal_values.samples.log` in the aggregate output directory.
